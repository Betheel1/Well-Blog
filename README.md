# 🌿 Wellness Wisdom – Well-Blog

**Wellness Wisdom** is a wellness and health information blog designed to share helpful articles and resources that encourage healthy living and overall well-being.

The project focuses on providing a clean, user-friendly, and responsive interface where visitors can explore wellness-related content.

## ✨ Features

- **Featured Articles:** Highlight important wellness and health articles.
- **Article Categories:** Organize content into different wellness topics.
- **Article Search:** Help users find relevant articles.
- **Responsive Design:** Provide a smooth experience across desktop, tablet, and mobile devices.
- **User-Friendly Interface:** Simple navigation and an accessible layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Vite

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Betheel1/Well-Blog.git
```

### 2. Navigate to the project folder

```bash
cd Well-Blog
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal (usually `http://localhost:5173/`) in your browser.
